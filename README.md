# PaddingFormatNum

## 概要
  連番になっているファイル名の桁数が合わない部分を、０で埋めるスクリプトです。  
  　例）　1.txt ⇒ 001.txt、2.jpg ⇒ 002.jpg　... 100.png ※変更なし

## 仕様
- スクリプトのファイルが配置されているフォルダのファイルを対象にする。
- 以下のファイルは対象外として、名前変更をしない。
  - フォルダ内にある子フォルダおよびその中にあるファイル
  - ファイル名が連番以外のファイル
  - ファイル名は連番だが、全角になっているファイル
- 処理を実施した際、変更前後のファイル名をログファイルへ出力する
- ログファイルは、実行フォルダに「Log_PaddingFormatNum_yyyyMMdd.txt」として作成する
- ログファイルを作成できない場合は、処理を実行しない。
  
## 使用方法
1. Powershellフォルダの中にある「PaddingFormatNum.bat」「PaddingFormatNum.ps1」をダウンロードします。
2. ダウンロードした２つのファイルを、処理したいファイルが存在するフォルダに移動します。
3. 「PaddingFormatNum.bat」を実行します。　※実行するフォルダによっては、管理者権限が必要になる可能性があります。

## フォルダ
- Powershell　・・・　スクリプトファイルが格納されているフォルダです。

## 補足
### ログファイルについて
- ログは以下の形式で作成
  ```txt:Log_PaddingFormatNum_yyyyMMdd.txt
  ExecStart:yyyy/MM/dd HH:mm:ss
  　Succeed::変更前のファイル名 _ 変更後のファイル名
    ・
  　・
  　・
  ExecEnd:yyyy/MM/dd HH:mm:ss
  ```
